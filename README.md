Accessibility HTML / CSS / JS Assignment

## ДЗ№1
Проверил страницу тремя инструментами для проверки доступности на странице:
- Lighthouse
- axe DevTools
- IBM Accessibility

### Lighthouse
  Не подсчитывает кол-во проблем, выдает в процентном соотношении - 57. Указывает на элементы с проблемами, можно перейти на проблемный элемент в коде, описывает какая проблема, но не дает вариантов решения


### axe DevTools
  Выдал 62 проблемы. Указывает на элементы с проблемами, описывает какая проблема, предлагает возможные решения, подсвечивает элементы на странице
  Дополнительные возможности проверки за плату


### IBM Accessibility
  Выдал больше всего ошибок - 144, включая рекомендации. Подсвечивает элемент на странице
  Есть отличная штука: Keyboard tab stops
  Можно установить через пакетный менеджер для автоматической проверки
